# Security policy

Legofolio is under active pre-launch development. Do not place API secrets, OAuth client secrets, private keys, service-role keys, passwords, or marketplace credentials in issues, source files, browser code, commits, or screenshots.

## Reporting a vulnerability

Do not open a public issue containing exploit details or personal information. Use GitHub's private vulnerability reporting/security-advisory feature for this repository. The repository owner must configure a monitored security email before public launch.

Include the affected page or function, reproduction steps, impact, and a safe proof of concept. Do not access other users' information, disrupt service, perform denial-of-service testing, or retain data encountered during testing.

## Supported version

Only the current production deployment will receive security fixes after launch. The project is not currently represented as production-ready.
